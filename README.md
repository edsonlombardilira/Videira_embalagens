# Website Videira Embalagens - Rua dos Missionários (Santo André - SP)

Novo design colorido, festivo e moderno desenvolvido para destacar os segmentos de **Festas, Confeitaria e Delivery**, garantindo clareza total de localização no endereço da **Rua dos Missionários**.

## 🎨 Identidade Visual
- **Tipografia Alegre:** Uso da fonte *Fredoka* para títulos e *Nunito* para textos.
- **Paleta de Cores Festiva:** Laranja Coral, Amarelo Girassol, Rosa Confeitaria e Verde Água.
- **Foco em Conversão:** Botões diretos para WhatsApp e mapa destacado.
